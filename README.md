# 九𪼇先生醫案（1898 年跋，臺灣國家圖書館 06120） / Jiu 𪼇 xian sheng yi an [Medical Case Records of Master Jiu 𪼇]: Transcription Dataset

《九𪼇先生醫案》是臺灣國家圖書館藏晚清漢文醫案，原件以六個物理冊收藏。順列個別病者、症候、方條和跨頁複診，可供追查晚清醫案的記錄方式與照護歷程。末冊署光緒戊戌秋（1898），跋文可與館目所載謝元福互查。

This late Qing manuscript of individual case records is preserved in six physical bindings at the National Central Library, Taiwan. Entries record patients, symptoms, prescriptions, and subsequent visits, often across openings. The sixth binding concludes with a postface dated autumn 1898, attributed in the library catalogue to Xie Yuanfu.

同一129頁 PDF 覆蓋六冊，逐頁區分內外封、襯紙、病例欄、薄墨夾注及難辨字。

The 129 images cover all six bindings. The transcription indexes each opening, covers, endpapers, case columns and visible notes.
